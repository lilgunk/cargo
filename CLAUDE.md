# Проект

Дипломный проект:
Aplikacja wspomagająca planowanie załadunku pojazdów dostawczych

## Стек

- React
- TypeScript
- Vite
- TailwindCSS
- Node.js (планируется)
- Express (планируется)
- SQLite (планируется)

## Цель

Приложение для визуального планирования загрузки грузового автомобиля.

Пользователь может:
- выбрать автомобиль
- задать размеры грузов
- добавлять коробки
- видеть пошаговую укладку
- просматривать 2D/3D визуализацию

## Важно

- Двигаться маленькими шагами
- Не создавать огромную архитектуру
- Не усложнять проект
- Код должен быть читаемым
- Использовать TypeScript типы
- Разделять компоненты по папкам
- Не добавлять Redux
- Использовать функциональные React components

## Запуск

```bash
npm run dev
```

Сервер поднимается на **http://localhost:5173**

Если ошибка `Cannot find native binding` у rolldown — удалить node_modules и переустановить:

```bash
rm -rf node_modules package-lock.json
npm install
```

### Этап 2 — Интерактивная логика (2026-05-25)

**Реализована рабочая логика** добавления/удаления грузов и укладки.

**Изменения:**

- `useCargoStore.ts` — хук-стор с полной логикой:
  - `addCargo(fields)` — добавляет груз с автоматическим цветом из палитры COLORS
  - `removeCargo(id)` — удаляет груз по id
  - `placeCargo(items, vehicle)` — жадный алгоритм укладки (полки: идём по X, при переполнении — новая строка по Y, при переполнении — новый слой по Z)
  - Вычисляемые метрики: `totalWeight`, `totalItems`, `usedVolume`, `maxVolume`, `freeVolume`, `occupancy`

- `LeftPanel.tsx` — форма с валидацией:
  - Поля: длина, ширина, высота (мм), вес (кг), количество
  - Валидация: проверка > 0 и проверка, что груз влезает в габариты авто
  - Ошибка отображается под кнопкой добавления
  - Список грузов: цвет, размеры, вес, количество; кнопка удаления при hover
  - Итого: общий вес и количество мест в подвале списка

- `ContainerView.tsx` — 3D SVG с реальными коробками:
  - `VanSVG` рендерит `placed` единицы с 3D-эффектом (три грани)
  - `TopViewSVG` рендерит вид сверху с реальными позициями
  - Легенда цветов под 3D-видом

- `RightPanel.tsx` — метрики из стора:
  - Бейдж: Оптимально / Частично / Мало груза
  - Прогресс-бар заполненности
  - Список размещённых грузов с позицией первого экземпляра

**Типы (`types/index.ts`):**
- `PlacedUnit` — расширяет CargoItem координатами x/y/z и полем cargoId

**Данные остались прежними** (mockData.ts не менялся).

### Этап 3 — Алгоритм EP + визуальные фиксы (2026-05-26)

**Алгоритм укладки полностью переписан** на Extreme Point (EP) bin packing.

**`useCargoStore.ts` — ключевые изменения:**

- `getAllOrientations(l, w, h)` — возвращает до 6 уникальных ориентаций коробки (все перестановки L/W/H)
- `optimizeCargo` — EP алгоритм:
  - Сортировка по объёму (большие первыми)
  - Начальная точка EP: (0, 0, 0)
  - Для каждой коробки: перебор всех EP × всех ориентаций → выбор минимального скора
  - Скор: `z * 1_000_000 + x * 1_000 + y` (пол → кабина → стена y=0)
  - После размещения: 3 новых EP (справа, рядом, сверху)
- **Гравитация к стене y=0:** после выбора EP-позиции коробка сдвигается к стене — ищем `wall = max(r.y + r.width)` среди коробок в том же x-z срезе
- `isSupported` — коробка должна стоять на полу (z=0) или на другой коробке
- `addCargo` теперь возвращает `boolean` — блокирует добавление если суммарный объём грузов превысит объём кузова

**`ContainerView.tsx` — фикс вида сверху:**
- `TOP_W` исправлен с 400 на 330 px (реальная ширина грузового отсека в SVG)
- Добавлен `clipPath` — коробки не вылезают за пределы кузова

**`RightPanel.tsx`:**
- Кнопка «Запустить оптимизацию» подключена (`onClick={store.optimize}`)

**`LeftPanel.tsx`:**
- Валидация `addCargo`: если возвращает `false` — показывает ошибку «Не хватает места в кузове»
- Миниатюры транспорта: если у авто есть `images` — показывает фото вместо SVG (`object-contain`)
- Размер миниатюр: `aspect-[10/9]` (на ~20% выше чем было)

**`types/index.ts`:**
- `Vehicle` получил необязательное поле `images?: { front: string; side: string }`

**`data/mockData.ts`:**
- Mercedes Sprinter L3H2 получил `images: { front: '/vehicles/sprinter-l3h2-front.png', side: '/vehicles/sprinter-l3h2-side.png' }`

**`public/vehicles/`:**
- `sprinter-l3h2-front.png` — фото спереди
- `sprinter-l3h2-side.png` — фото сбоку
